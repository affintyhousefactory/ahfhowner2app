## Vous exploitez un camping ou un établissement de plein air ?

Vous envisagez de créer de nouveaux hébergements, de valoriser une parcelle disponible ou de faire évoluer votre offre ?

**Howner peut étudier avec vous un projet d’implantation de studios ARKO**, en tenant compte de votre site, de vos usages, de vos contraintes d’accès et des premières contraintes réglementaires identifiées.

L’objectif n’est pas de vous proposer immédiatement un nombre de modules.

Nous commençons par étudier avec vous :

- le potentiel de la parcelle ;
- les implantations possibles ;
- les modèles ARKO adaptés ;
- les contraintes d’accès, de transport et de pose ;
- les besoins en raccordements ;
- les premières contraintes d’urbanisme ;
- le phasage possible du projet ;
- une première enveloppe économique.
