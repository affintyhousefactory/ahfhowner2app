## Article prêt à intégrer

### Le vrai budget commence là où s’arrête le prix catalogue

Un prix affiché peut couvrir le studio lui-même sans couvrir tout ce qui permet de l’installer réellement sur une parcelle. Pour comparer correctement deux offres, il faut reconstituer une enveloppe complète.

> CTA : **Construire ma configuration** → `/configurer/v2`

### Budget total = studio + terrain prêt à recevoir le studio

À intégrer dans le chiffrage :
1. produit et niveau de finition ;
2. études nécessaires ;
3. fondations ou supports ;
4. transport ;
5. grutage / manutention ;
6. accès chantier ;
7. raccordement électrique ;
8. eau potable ;
9. évacuation des eaux usées ;
10. éventuelle adaptation de l’assainissement ;
11. terrassements ;
12. taxe d’aménagement ;
13. aménagements extérieurs ;
14. options de confort et mobilier.

### Les coûts cachés viennent souvent du terrain

Un accès étroit, une pente, une distance importante jusqu’aux réseaux ou un système d’assainissement à adapter peuvent modifier fortement l’enveloppe. C’est pourquoi un prix produit ne doit jamais être présenté comme un coût final universel.

### Taxe d’aménagement : l’intégrer dès le début

Le simulateur officiel des taxes d’urbanisme rappelle que la création de surfaces closes et couvertes d’une hauteur supérieure à 1,80 m peut être taxable. Le montant dépend notamment de la surface taxable et des taux applicables localement.

### La comparaison Howner doit être faite “à prestations comparables”

Le configurateur doit servir à rendre visibles :
- le modèle ;
- les équipements ;
- les options ;
- les hypothèses ;
- ce qui reste à la charge du client ;
- les prérequis terrain.

Cette transparence vaut davantage qu’un prix d’appel difficile à comparer.
